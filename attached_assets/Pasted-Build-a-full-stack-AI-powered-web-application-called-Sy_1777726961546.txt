Build a full-stack AI-powered web application called **"Synorlab Interviewer"**.

## 🎯 PRODUCT OVERVIEW

This is a B2B SaaS platform for universities where students can upload a job description (JD) and practice mock interviews with an AI interviewer.

The system should:

1. Parse the uploaded job description
2. Generate interview questions based on the JD
3. Conduct an interactive interview (chat-based)
4. Evaluate answers and provide feedback + score

---
